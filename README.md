# Web Table Sorting Validation using Selenium

## Project Overview
This Python automation script validates that the **"Veg/fruit name"** column in a web table is sorted in ascending order after clicking its column header. The script demonstrates Selenium automation for web tables and basic test validation using Python.

---

## Tools & Technologies
- Python 3.x  
- Selenium WebDriver  
- Google Chrome & ChromeDriver  

---

## Skills Demonstrated
- Selenium automation scripting  
- Locating web elements using XPath  
- Extracting data from web tables  
- Python list handling and sorting  
- Test validation using assertions  
- Headless browser execution for faster tests  

---

## Objective
1. Open the **Offers** page on the sample Selenium practice site.  
2. Click on the **"Veg/fruit name"** column header to sort the table.  
3. Capture all vegetable/fruit names from the first column.  
4. Compare the browser’s order of items with a Python-sorted list.  
5. Validate that the website’s sorting feature works correctly.
